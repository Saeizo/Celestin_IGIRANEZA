d) Compute Total Float and identify Critical Path & e) Is 12-week target achievable?
d) Critical Path: The path with zero float. Based on the table above, the path is A -> B -> C -> D -> F -> G -> H. (Notice Task E is excluded because it has 2 weeks of float).

h) Effect of increasing a critical-path activity by 1 week
Explanation: If a critical path activity (for example, Task D - Backend Development) is delayed by 1 week, the entire project duration will increase by 1 week. The new project completion time will be 13 weeks. This happens because critical tasks have zero float; any delay in them directly pushes back all subsequent tasks and the final deployment.
